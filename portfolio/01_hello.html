Project Hello Quad

3D Graphics

Project Overview

This project is a 'Hello Quad' rendering assignment designed to build a solid foundation in the graphics pipeline using C++ and OpenGL. Instead of calling native gl functions directly, I focused on building a platform-independent and safe rendering architecture. To do this, I implemented a custom C++ wrapper class (GL.hpp) that seamlessly supports OpenGL 3.3 Core, OpenGL ES 3.0, and WebGL 2.

Tasks Completed

  • Object-Oriented OpenGL Wrappers: Encapsulated core OpenGL objects like VertexBuffer, IndexBuffer, VertexArray, and Texture into C++ classes. I applied the RAII pattern to ensure robust resource management and prevent memory leaks.
  • Cross-Platform Compatibility: Wrote all rendering logic exclusively through the GL.hpp interface, making the code fully compatible across desktop (OpenGL 3.3), mobile (ES 3.0), and web (WebGL 2) environments.
  • Time-Based Dynamic Animation: Hooked up an environment variable (uTime) and some trig functions to the shaders. The vertex shader handles smooth circular movement, while the fragment shader dynamically cycles the colors over time.
  • Custom Texture Mapping: Brought in a hand-drawn pixel art character (paint_me.png) and successfully mapped it onto the rotating quad mesh.
